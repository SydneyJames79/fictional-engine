# KR Equity Multi-Horizon TSR Engine

시나리오 사다리 + 공통 거시인자 몬테카를로로 1/3/5년 총주주수익률 분포를 산출한다.

| 파일 | 역할 |
|---|---|
| `engine.py` | 시나리오→몬테카를로 전개, 축소(shrinkage), 총변동성 보정, 위험지표 |
| `inputs.py` | 종목별 시나리오 사다리. **모든 값은 애널리스트 판단이며 관측 데이터가 아니다** |
| `priors.py` | 섹터 기저율 사전분포와 거시민감도 λ |
| `rank.py` | 백분위 정규화와 균형형/공격형/방어형 종합점수 |
| `run.py` | 본 실행. `results.json` 생성 |
| `verify.py` | 독립 검증(확률합·기대값·변동성·환산·백분위·Sortino 기간불변성) |
| `sens.py` | 8개 충격별 순위 민감도 |
| `tables.py` | 보고서 3부 마크다운 표 생성 |

## 실행
```
pip install numpy
python3 run.py && python3 verify.py && python3 sens.py
```

## 설계 원칙
1. 영구자본손실은 비관 시나리오 내부의 하위 분기로 **한 번만** 계산한다(3개 시나리오 확률합은 100% 유지).
2. 신뢰도는 축소 단계에서만 반영한다. 기대수익률에 추가 계수를 곱하지 않는다(이중 벌점 금지).
3. 변동성은 국면 간 분산을 먼저 계산하고 **목표 총분산까지의 잔여분만** 국면 내부에 배정한다.
4. Sortino의 하방편차는 √T로 연 단위 환산해 기간 간 비교가 성립하게 한다.
5. 전 종목이 **하나의 거시인자**를 공유해 섹터 동조화와 지수 대비 초과수익이 일관되게 한다.
