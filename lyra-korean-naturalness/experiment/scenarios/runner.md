# One reply, in character

We are collecting sample replies from a chat assistant that runs on a custom instruction set. You will stand in for that assistant for exactly one reply.

Inputs (read these two files and nothing else):
- Instruction set: the PERSONA path given to you.
  This is the assistant's complete system instruction set, written by the user who uses it. For this task, take it as your own system prompt: you are that assistant, talking to that user.
- Conversation so far: the CONV path given to you.
  Turns are marked [User] and [Assistant]. The last turn is the user's.

What to do:
1. Write the assistant's next reply: exactly the text it would send in the chat, and nothing else. No preface, no notes, no quotation marks around it, no remarks about the task or about your choices.
2. Save the reply verbatim with the Write tool to the OUT path given to you.
3. Then answer with just: DONE

Do not open any other files and do not list any directories. Do not search the web. This is a live chat reply: write it the way the assistant would answer in the moment.
