# robustness.md — 강건성 시험

계산 도구: `tools/robustness.py`. 가중치는 유리수(Fraction)로 합계 1을 검증한 뒤 계산했다. 전체 출력은 `robustness_raw.txt`에 있다.

- 보조 지수: S = Σ(w_i × d_i). +는 「건축」(A) 쪽, -는 「여행의 미래」(B) 쪽이다.
- S는 품질 점수도, 승리 확률도 아니다.
- U인 축은 [-2, +2]로 두고 S의 범위를 계산했다.

## 1. 최종 축별 판단의 14개 설정 결과

최종 d = (A 0, B −1, C −1, D 0, E −1, F 0). 이 판단표에는 U가 없다.

| 설정 | S | 방향 |
|---|---|---|
| 1 기본 (.2 .2 .2 .2 .1 .1) | −0.500 | B |
| 2 균등 (1/6씩) | −0.500 | B |
| 3 A축 제거 | −0.625 | B |
| 3 B축 제거 | −0.375 | B |
| 3 C축 제거 | −0.375 | B |
| 3 D축 제거 | −0.625 | B |
| 3 E축 제거 | −0.444 | B |
| 3 F축 제거 | −0.556 | B |
| 4 A축 40% | −0.375 | B |
| 4 B축 40% | −0.625 | B |
| 4 C축 40% | −0.625 | B |
| 4 D축 40% | −0.375 | B |
| 4 E축 40% | −0.667 | B |
| 4 F축 40% | −0.333 | B |

검산 예시(설정 4, D축 40%): 나머지 다섯 축은 기본 비율대로 합계 0.6이 되게 줄인다. 그러면 A·B·C가 각 0.15, E·F가 각 0.075다. S = 0.15·0 + 0.15·(−1) + 0.15·(−1) + 0.4·0 + 0.075·(−1) + 0.075·0 = −0.375.

**결과**: 14개 설정 모두에서 방향이 유지된다. 역전, 동률, 미결정은 없다. 이유는 구조적이다. A 쪽 값이 하나도 없으므로 어떤 양의 가중치를 주어도 S는 0보다 작다. 따라서 가중치 강건성은 이 판단표에서는 자명한 결과다. 판정을 실제로 흔드는 것은 가중치가 아니라 축별 판단, 곧 독해다(아래 2–4).

## 2. 독립 비교 심사자 사이의 판단 차이

| 판단표 | d (A~F) | 기본 S | 14개 설정 |
|---|---|---|---|
| J_1 (「건축」 먼저 제시) | −1 −1 −1 +1 −1 0 | −0.500 | 모두 B 쪽 |
| J_2 (「여행의 미래」 먼저 제시) | −1 −1 −1 0 −1 0 | −0.700 | 모두 B 쪽 |
| 최종 | 0 −1 −1 0 −1 0 | −0.500 | 모두 B 쪽 |

- 두 심사자의 차이는 축 D 하나다. J_1의 +1은 원문 반례로 철회되었다(revisions 5).
- 두 번의 실행만으로 이 차이를 제시 순서 효과로 볼 수는 없다. 제시 순서를 바꿔도 종합 방향은 같았다.
- 두 심사자는 같은 기반 모델을 쓰는 별도 컨텍스트다. 방향 일치는 독립 증거 두 개가 아니다.

## 3. 가장 강한 대안 독해를 받아들일 때

대안 독해: 「건축」의 반복과 추상은 제사의 '한 메시지만 반복하는 글'을 의도적으로 수행한 것이고, ¶2의 '이곳'은 이름 붙기 전의 '말'이다.

| 시나리오 | d (A~F) | 기본 S | 14개 설정 중 |
|---|---|---|---|
| 대안 독해 수용: C → 0, D → +1(J_1 관점) | 0 −1 0 +1 −1 0 | −0.100 | B 쪽 11, A 쪽 2(B축 제거, D축 40%), 동률 1(E축 제거) |
| 대안 독해에 형식 대등론(가설 B 검사 1)까지 수용: B → 0 | 0 0 0 +1 −1 0 | +0.100 | A 쪽 11, 동률 1(균등), B 쪽 2(D축 제거, E축 40%) |
| 가설 B 검사의 결론을 그대로 적용 | 0 0 −1 0 −1 0 | −0.300 | 모두 B 쪽 |
| 가설 B 검사 결론에서 축 D를 A 근소 우세로 | 0 0 −1 +1 −1 0 | −0.100 | B 쪽 11, A 쪽 2, 동률 1 |
| 축 C를 미결정(U)으로 두면 | 0 −1 U 0 −1 0 | [−0.700, +0.100] | 기본을 포함한 11개 설정에서 범위가 0을 포함한다. B 쪽 3(C축 제거, B축 40%, E축 40%) |

**영향받는 축**: C(¶2 독해), D(단계화에 대한 가치 가중), B(형식 대등론).

**순위가 뒤집히는 조건**: 기본 가중치에서는 이 세 축 모두에서 「건축」에 가장 유리한 쪽을 택할 때만 뒤집힌다(S = +0.1). 한 축만 바뀌면 기본 S는 −0.3이고, 두 축이 바뀌면 −0.1이다. 다만 한 축만 바뀌어도 가중치를 극단적으로 옮기면 뒤집힐 수 있다. 예를 들어 D만 +1로 바꾸고 D축을 40%로 두면 S는 +0.025로 A 쪽이 된다.

## 4. 중복 반영 점검

- 「건축」 대립쌍의 약점은 X가 세 번 감점했다. 최종 판단에서는 축 A에서만 셌다.
- 「여행의 미래」의 행 경계(B57–B58)는 축 B에서만 셌다. 축 E는 자기 정정과 돌의 부정 목록을 근거로 한다.
  - 시험: 축 E에서 행 경계(B57–B58)를 빼도 B 쪽 근거로 자기 정정(B58–B59)과 돌의 부정 목록(B64–B65)이 남는다. 이것만으로도 A 쪽 근거인 A11의 말씨 전환 및 A8.4–A9.1의 가능형 정서와 대비해 근소 우세가 유지된다고 판단했다. 이 판단이 틀려서 E가 0이 되면 S는 −0.4가 되고, 방향은 그대로다.
- 「건축」 시제의 호는 축 B에서 셌다. 축 D는 단계의 순서와 제사–결말의 호응을 근거로 한다. 이 호를 축 D에서 추가로 인정해 D를 +1로 두면 S는 −0.3이다.

## 5. 결론

- 확인된 사실: 시험한 14개 가중 설정에서 판정 방향은 유지된다. 이는 '모든 가능한 기준에서 우월하다'는 뜻이 아니다.
- 판정이 기대는 것: 축 B·C·E의 근소 우세 세 개다. 판정이 흔들리는 조건은 가중치가 아니라 독해다. 세 개의 축(B·C·D)에서 「건축」에 유리한 독해가 한꺼번에 성립해야 뒤집힌다.
- 그래서 판정은 '근소 우세'로만 말할 수 있다. '뚜렷한 우세'로 말할 근거는 없다.
