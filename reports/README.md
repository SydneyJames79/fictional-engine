# 국내 26개 종목 1·3·5년 기대 TSR 순위

| 파일 | 내용 |
|---|---|
| `kr26_tsr_ranking_20261022.md` | 본 보고서. 정보 기준 2026-10-22 15:10 KST. 부록 B-2에 10/29 정보를 반영한 참고 순위가 있다 |
| `kr26_metrics_20261022.csv` | 종목·기간별 최종 지표와 순위(본 순위, UTF-8 BOM) |
| `kr26_update_20261029.csv` | 10/29 갱신 참고 순위와 지표(UTF-8 BOM) |
| `kr26_data/` | 계산 입력(`inputs.json`)과 결과(`results.json`, 갱신분 `results_u.json`, `u_summary.json`) |

투자 권유가 아니며 매매 지시나 투자비중을 제시하지 않는다. 시나리오 확률과 손실확률은 에이전트들의 주관적 추정과 모형 가정에서 나온 값이다.
